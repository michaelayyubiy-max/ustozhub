# UstozHub 🇺🇿
> O‘zbekiston uchun onlayn repetitorlik platformasi va Telegram bot integratsiyasi (@Ustozhubuzbot)

## Xususiyatlari
- **Bosh sahifa (`index.html`)**: Platforma imkoniyatlari, ota-onalar monitoringi, fanlar katalogi.
- **Ustoz qidirish (`tutors.html`)**: Preply uslubidagi ko‘p bosqichli filtrlar, video-tanishtiruv, escrow kafolati va Click/Payme/Uzum to‘lovlari.
- **Interaktiv dars xonasi (`classroom.html`)**: HTML5 Canvas interaktiv doskasi, jonli video aloqa, darslik slaydlar, testlar, lug‘at va chat.
- **Telegram orqali parolsiz kirish**: `@Ustozhubuzbot` orqali 6 xonali OTP kod bilan ro‘yxatdan o‘tish va kirish.

## Ishga tushirish
```bash
python3 server.py
```
Server `http://localhost:5173` yoki `$PORT` portida ishga tushadi.
